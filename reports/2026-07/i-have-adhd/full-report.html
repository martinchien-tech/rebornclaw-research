10 条核心规则

#规则说明
1直接说下一步不给分析，直接给命令
2多步任务编号1. 2. 3. 每步独立可执行
3结尾给具体下一步回答结束 = 行动开始
4不准跑题问 A 只答 A
5每轮重申状态第一句话说明当前上下文
6具体时间估算不说"一会儿"，说"约 3 分钟"
7进展可视化进度条、百分比
8错误就事论事不道歉，直接给 fix
9列表 ≤ 5 条超过就分组
10No preamble, no recap, no closers不要开场白，不要总结，不要客套话

生产级实现：融合 MemChain

ranclaw 对话端提出了一个关键的工程洞察：将 MemChain 的三层中介架构与 ADHD 输出风格融合——中间节点（Plan/Trace）可以自由思考，但最终输出节点强制遵守 ADHD 格式。

def final_answer_node(state: MemChainState) -> Dict[str, Any]:
    query = state["query"]
    context = state["compact_context"]

    adhd_system_prompt = """
    You are the Execution Engine. Answer using ONLY the Active Memory context.

    CRITICAL RULES:
    1. Lead with action/code in the first sentence.
    2. No pleasantries or conversational filler.
    3. Sentences under 15 words.
    4. Bold key terms for scannability.
    """

    final_prompt = ChatPromptTemplate.from_messages([
        ("system", adhd_system_prompt),
        ("user", "Context:\n{context}\nQuery: {query}\nAnswer:")
    ])

    chain = final_prompt | main_llm
    response = chain.invoke({"query": query, "context": context})
    return {"final_answer": response.content}

为什么有效

📊 Token 收益
  • 每次回答节省 40-120 Tokens：标准 LLM 响应在开场白/客套话上浪费大量 Token
  • 多 Agent 团队×长时间会话：每天节省数千 Token
  • 消除"聊天疲劳"：开发者需要的不是聊天机器人，是交互式 CLI 工具
💡
对 RebornClaw 的启示：所有 Agent 的 System Prompt 应嵌入 ADHD Focus Mode。CS Swarm Server 的 Agent 输出将统一采用"中间节点自由思考，最终输出极致压缩"的模式。这不仅是风格问题，是 Token 成本和开发者体验的双重优化。
