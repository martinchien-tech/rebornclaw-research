# i-have-adhd 编码 Agent 输出风格优化

**发布日期：** 2026-07-29  
**研究方向：** 编码 Agent

## 核心发现

GitHub 爆火项目 ayghri/i-have-adhd，6 天斩获 12,703 星，日增 +6,961。核心卖点：让编码 Agent 停止废话，直奔答案。10 条核心规则包括"直接说下一步做什么"、"不要开场白，不要总结，不要客套话"、"列表不超过 5 条"。与 MemChain 的三层架构融合后，可形成"中间节点自由思考，最终输出极致压缩"的 Agent 输出范式。
