**研究方向：** AI 安全 / 多 Agent 安全体系

## 摘要
微软 Project Perception 是一个由红蓝绿三色 AI 智能体构成的自主安全闭环系统。本文从项目全景、行业评价、落地实用性、企业级 AI 安全新范式等维度进行全面分析。

## 核心发现
- 红队/蓝队/绿队三色 Agent 协同，实现"感知→推理→自动执行"闭环
- 多模型混血架构（MAI-Cyber-1-Flash + GPT-5.6），Token 成本砍掉 50%
- 绝非 PPT 炫技，在代码加固和漏洞挖掘方面已工业级落地
