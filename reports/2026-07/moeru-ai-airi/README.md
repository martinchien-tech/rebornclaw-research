# moeru-ai/airi 深度架构与工程研究

**发布日期：** 2026-07-29  
**研究方向：** AI 数字生命

## 核心发现

moeru-ai/airi 是开源社区的现象级爆品（4.4 万星），目标是复刻全球顶流 AI VTuber "Neuro-Sama" 的技术高度。它是一套极其硬核的分布式多智能体实时编排系统，核心架构包括 Plast Mem 长期记忆引擎、WebRTC 零延迟语音网格、Minecraft/Factorio 游戏代理层。对 RebornClaw 的 Agent 记忆层设计有直接参考价值。

## 关键数据

- GitHub 4.4 万星，日增 +796
- 核心技术：Plast Mem、WebRTC、YOLO 视觉、Minecraft/Factorio 代理
- 部署：自托管（Self-hosted），支持本地 LLM
