# Kimi K3 大模型深度分析

**发布日期：** 2026-07-29  
**研究方向：** 大模型趋势

## 核心发现

月之暗面（Moonshot AI）于 2026 年 7 月 27 日释放了全球首个跨入 3 万亿参数级别的开放权重模型（总参数 2.8T，MoE 架构）。Kimi K3 在长程编程和多步骤 Agent 编排上具备统治级战斗力，Frontend Code Arena 以 1679 分击败 Claude Fable 5（1631 分），全球第一。

## 关键数据

- 总参数 2.8T，激活参数 1040 亿（104B）
- 896 个路由专家，KDA + AttnRes 双引擎
- 1.5 TB 完整权重，8 张 RTX 5090 仅够单并发测试
- Frontend Code Arena 1679 分（全球第一）
- 综合智能指数全球第三（仅次于 GPT-5.6 Sol/Luna 和 Claude Fable 5）
