# Multi-Agent 归因链信任体系技术提案

**发布日期：** 2026-07-28  
**研究方向：** Multi-Agent 信任

## 核心发现

基于归因链信任体系，构建 Multi-Agent 信任链的工程化解决方案。核心思路是"溯源式审计"——不追问动机，只追踪证据链。输出包含决策溯源 JSON（output + input_trace + signature），可被另一个 Agent 审计，形成信任链闭环。
