# yorukot/superfile 现代化终端文件管理器深度调研

**发布日期：** 2026-07-29  
**研究方向：** 开源工具

## 核心发现

yorukot/superfile 由中国开发者 Yorukot 发起，是一个基于 Go 语言 + Bubble Tea 框架的现代化终端文件管理器。它打破了传统命令行工具"反人类"的刻板印象，将 Windows 资源管理器的高可视化交互模式注入到纯文本终端中。支持多面板、20+ 主题、鼠标点击拖拽，大文件 I/O 异步并发处理。

## 关键数据

- 开发语言：Go 1.21+
- 框架：Bubble Tea / Lip Gloss
- 特色：多面板、实时预览、模糊搜索、20+ 主题
- 对比：Yazi（Rust）→ 硬核，superfile（Go）→ 低门槛
