# book-to-skill 深度分析

**研究方向：** AI Agent 生态 / 技能化知识库 / Skill-driven
**作者：** Martin Chien | RebornClaw Technology Co., Ltd.

## 摘要
virgiliojr94/book-to-skill 是 GitHub 今日爆火项目（+1,421/天），将技术书 PDF 转换为 Claude Code Skill。本文从核心痛点、范式转变、对 Agent 生态的影响等维度进行深度分析。

## 核心发现
- 解决"发现循环税"——编译时解决而非运行时解决，大幅降低 Token 成本
- 从"检索（RAG）"走向"推理与执行（Skill-driven）"
- "技能即资产"——未来竞争拼的是 Skill 库丰富度，而非 Agent 框架
